# Changelog & Release Notes

## [Version 0.6] - 2026-09-23

### 🌟 Нововведения

#### Модуль «Радар Шкрели (Long / Short)»
* **Мониторинг позиций Мартина Шкрели**:
  * Добавлена отдельная навигационная вкладка `Радар Шкрели (L/S)` для отслеживания 35 позиций портфеля (17 Longs vs 18 Shorts).
  * Параллельная загрузка актуальных котировок Yahoo Finance для всех бумаг портфеля.
* **Аналитика корзин Long vs Short**:
  * Автоматический расчет средней доходности Long-корзины и эффективного P&L Short-корзины (падение цены акции интерпретируется как прибыль шорта).
  * Расчет рыночно-нейтрального синтетического спреда (`L/S Spread / Alpha`).
* **Интерфейс и управление**:
  * Два режима отображения: «Две колонки (Long / Short)» и «Сводная таблица».
  * Интерактивные спарклайны (3M), шкалы дневного диапазона цен (Day Range).
  * Быстрый переход на детальный интерактивный график любого актива в один клик.
  * Пакетный импорт тикеров в список наблюдения вочлиста, выгрузка в CSV и копирование тикеров.

## [Version 0.5] - 2026-09-11

### 🌟 Основные нововведения

#### 1. Модуль «Google Портфель»
* **Прямая синхронизация с Google Таблицами**:
  * Загрузка данных по ссылке на таблицу без необходимости сложных API-ключей (через защищенный экспортный эндпоинт).
  * Парсинг цен входа от `16.06` и цен среза от `10.09`.
  * Скачивание готового шаблона Google Sheets с авто-формулами `GOOGLEFINANCE`.
* **Селектор портфелей / стратегий**:
  * Разделение на идеи: `Все активы`, `Основной портфель`, `Six sectors`, `Infa plus banks`, `AI plus finance`.
  * Полное удаление названий чат-ботов (`GEMINI`, `CLAUDE`) и очистка кэшированных данных.
  * Индикативный бенчмарк `NASDAQ:ACWI` вынесен из списка выбора портфелей в отдельную карточку сравнения внизу.
* **Корректное отображение дат**:
  * Для отдельных портфелей добавлен маркер `(сформирован от 16.06)`.
  * Для «Все активы» дата в заголовке убрана во избежание путаницы при добавлении портфелей от других дат.
  * Убрана жестко привязанная дата из общего селектора.
* **Динамический график в стиле Google Finance**:
  * Полная адаптивность временных шкал: `1Д`, `5ДН`, `1МЕС`, `6МЕС`, `С1ЯН`, `1ГОД`, `5ЛЕТ`, `МАКС`.
  * Адаптивная ось X (часы для `1Д`, дни недели для `5ДН`, даты для `1МЕС`-`1ГОД`, месяцы/годы для `5ЛЕТ`/`МАКС`).
  * Хронологическое сведение котировок (LOCF) с параллельным кэшированием цен constituents.
  * Плавное переключение таймфреймов без скачков и мерцания (`keepPreviousData`).
  * Возможность наложения сравнительной линии бенчмарка `ACWI`.
  * Удалены неточные оранжевые кружки «ключевых моментов».
* **Таблица позиций и аналитика**:
  * Доли активов (Asset Allocation bar) с цветовой дифференциацией.
  * Таблица из 10 колонок с подсчетом P/L в долларах и процентах по отношению к цене входа.
  * Итоговый блок доходности и расчет Альфы (Alpha vs ACWI).

#### 2. Интерфейс и рабочая область
* **Сворачиваемый список наблюдения**:
  * Панель списка бумаг закреплена слева с возможностью переключения направо кнопкой `[⇄]`.
  * Кнопка `[Свернуть список] / [Развернуть список]` в шапке и на самой панели.
  * Сохранение выбранной стороны в `localStorage`.
  * Возвращена исходная центрированная разметка `max-w-7xl` с аккуратными отступами по бокам.

#### 3. Удобство запуска
* Добавлен скрипт `run-server.bat` для быстрого запуска сервера на Windows в один клик.

## Инструкция по запуску на другом компьютере

1. **Клонирование репозитория**:
   ```bash
   git clone https://github.com/Developeran/beam-juniper-acorn-dune.git
   cd beam-juniper-acorn-dune
   ```

2. **Установка зависимостей**:
   ```bash
   npm install
   ```

3. **Запуск локального сервера**:
   * Через командную строку:
     ```bash
     npm run dev
     ```
   * Или на Windows просто дважды кликните по файлу **`run-server.bat`**.

4. **Открыть в браузере**:
   Перейдите по адресу: [http://localhost:8082](http://localhost:8082)
